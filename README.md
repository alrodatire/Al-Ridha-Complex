# Al-Roda-Complex
مجمع بركات الرضا لتجارة الإطارات والبطاريات، تأسس عام 1990 في النجف، بخبرة تمتد لأكثر من 36 عاماً في عالم الإطارات والبطاريات. نوفر مختلف الماركات والمناشئ بجودة مضمونة وإنتاج حديث وأسعار تنافسية، لخدمة تجار الجملة وأصحاب المركبات. مسيرة طويلة بُنيت على الثقة والجودة والسمعة الطيبة، ونواصلها لخدمة زبائننا بأفضل المنتجات
